
# Student Management System

## Project Overview
A simple web-based Student Management System that allows users to add, view, and delete student records.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Add student records
- View student details in a table
- Prevent duplicate roll numbers
- Delete student records

## Development Workflow
This project uses Git for version control, feature branches for development, and GitHub Actions for automated validation.
